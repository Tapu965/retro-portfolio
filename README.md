# Retro OS Portfolio

A portfolio designed as an old CRT computer. Visitors boot up the system and navigate desktop icons to explore About, Projects, Skills, Contact, and more.

## Stack
- Vite + React 18 + TypeScript
- Tailwind CSS (retro tokens)
- Zustand (window manager state)
- Framer Motion (animations)
- react-rnd (draggable windows)

## Dev
\`\`\`bash
pnpm install
pnpm dev
\`\`\`

## Build
\`\`\`bash
pnpm build
pnpm preview
\`\`\`
